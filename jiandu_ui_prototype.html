八、组件与视觉规范

前端开发可按以下组件拆分，保证 UI 一致。
颜色

墨色 + 纸色 + 竹木色

主文字 #201b16，背景 #f5f1e8，强调色 #8a5a2f，状态色少量使用。

字体

现代无衬线为主

正文使用系统中文字体；释文区可在后续加入宋体/仿宋样式切换。

布局

左目录 + 中内容 + 右图像

图文阅读固定三栏；检索与后台采用左筛选/表单、右结果/表格。

组件

SearchBar / FilterPanel

用于全文检索、高级筛选、条件组合、命中数量展示。

组件

ReaderPanel / ImageViewer

支持复制、仅文字、仅图片、图文并列、翻页、缩放、拖拽。

组件

AnnotationHighlighter

按词性、语法角色、指称对象、关键词命中进行高亮。

九、第二阶段 UI 交付顺序

建议先定低保真，再做前端页面；不要一开始纠结复杂 AI 页面。

1. 页面确认

确认 6 个页面是否覆盖本阶段。

2. 风格确认

确认纸本、墨色、竹木色设计方向。

3. 前台开发

先做首页、阅读页、检索页。

4. 后台开发

做上传、编辑、目录和图文映射。

5. 调试优化

处理响应式、窗口适配和交互细节。
